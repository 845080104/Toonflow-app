# 智核接入与持久化媒体任务

从视频节点点击「获取智核视频模型」，或在右上角模型选择器点击相应分类的获取按钮。目录仅查询该分类，切换分类会清除本轮勾选；只导入勾选的模型，其他已导入模型保持不变。支持名称、ID、标签搜索。

选中目录中的模型可查看标签、当前 Key 是否开通、参数和实时渠道报价。金额单位是算力；区分按次、按秒和每百万 token。起价以 `min_price` 为准，按 token 不把零基础价当免费。展开渠道详情查看离线标记、分辨率选项、参考图/视频额外费用及限制；完整平台计费说明保留。渠道由平台按 Key 策略派单，列表报价不是本次精确结算承诺。

图片、视频、音频优先走 `/v1/media/generate`，通过 `/v1/skills/task-status` 查询。按 `/v1/skills/models` 分类发现，并合并 `/v1/media/models` 参数。生成前重新读取当前模型详情，检查类型、Key 可用性、必填项和枚举。节点「模型参数」允许覆盖通用设置；参数分别按模型保存。原 `MiniMax-H3` ID 保留原生 `/v2` 协议兼容，新目录中的 `minimax-h3` 使用统一协议。

语言目录只显示语言模型，按模型声明分为 OpenAI Chat、Responses 或 Anthropic 配置；目前客户端未支持的 Gemini 原生协议明确禁用，不能把其模型误塞进 OpenAI 配置。语言导入复用现有设置保存队列。

普通图片、视频和音频节点使用后台任务：

- 本地 UUID 请求只提交一次；服务端在启动前先保存记录，与浏览器连接分离。
- 上游任务 ID 保存后才表示供应商接收；节点工具返回 `starting` 不能当作已提交成功。
- 刷新、离开画布只结束页面轮询，不取消后台任务。重新打开原节点按工作区与节点 ID 找回任务，恢复输出和错误。
- 支持智核原生/统一协议、Codex 图片的上游 ID 检查点。服务重启后，有 ID 的任务只继续查询；没有 ID 的处理中记录标为「提交结果待确认」，不自动重发创建请求。
- 查询失败保留 ID，可「继续查询」。手动停止只停止本地等待；不能保证撤销上游任务或费用。
- 各阶段、错误和最终输出保存在数据目录 `mediaJobs/`。目录 0700、记录 0600，原子写入；不保存 API Key 或原始 HTTP 鉴权。查询接口校验工作区绑定，只返回状态、阶段、日志、上游 ID 和结果路径。
- 工作区保留 `mediaJobApplied`，成功结果只自动写回一次，避免刷新覆盖后来手动替换的素材。

旧版没有记录上游 ID 的失败任务无法推断对应上游任务。本次将已有对话中明确的 H3 证书错误恢复为历史失败日志，没有重新生成。

## 验证边界

执行现有构建和类型检查，手动核对实际目录、价格、按类型筛选、勾选导入及刷新读取；用账户已完成的真实任务验证原生与统一协议的恢复分支，只发 GET。未为验证重新创建收费任务，完整新增生成及生成中刷新仍需下一次正常创作调用验证。专属局部重绘等浏览器后处理流程仍沿用各自生命周期。
